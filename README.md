# Ookujira 日历

一个轻量的 Windows 桌面日历与待办提醒工具，带课程表、专注计时和桌面伙伴「おおくじら」。数据保存在本机，可导入课程表并导出待办备份。

**当前版本：v1.26.1** · **平台：Windows 10/11 x64**

## 下载与安装

从 [GitHub Releases](https://github.com/Lucyio02-dev/ookujira-calendar/releases/latest) 下载 `Ookujira-Calendar-Setup-1.26.1.exe`，双击运行安装程序。安装程序允许选择安装目录，并创建桌面和开始菜单快捷方式。卸载应用不会自动删除个人数据。

Windows SmartScreen 可能会对尚未进行代码签名的新开源应用显示提示。请只从本项目的 GitHub Releases 下载安装包。

## 功能

- 月历、日程、待办、搜索、提醒与本周回顾
- 快速输入中文日期时间，支持桌面通知和系统托盘
- 课程表导入（XLSX、XLS、CSV、TSV、ICS）、课程提醒和周视图
- 专注计时、主题切换、JSON 数据备份与恢复
- 可召唤、拖动并与之互动的桌面伙伴
- 天气联动和离线缓存

提醒仅在应用运行时生效；系统通知也受 Windows 通知设置和勿扰模式影响。课程文件在本机解析；天气服务 Open-Meteo 需要联网，不需要 API 密钥。

## 从源码运行

需要 Node.js 20 或更新版本和 npm。

```powershell
git clone https://github.com/Lucyio02-dev/ookujira-calendar.git
cd ookujira-calendar
npm ci
npm start
```

在 Windows 上构建安装程序：

```powershell
npm run dist:win
```

安装包输出在 `dist/`。推送 `v*` 格式的版本标签后，GitHub Actions 会在 Windows runner 上构建安装包并发布 GitHub Release。

## 本地数据

应用使用 Electron 的用户数据目录。Windows 默认位于 `%APPDATA%\desktop-calendar-reminder\`，包含待办、课程、窗口布局和桌面伙伴状态。此目录独立于程序安装目录，卸载应用时会保留。建议定期使用应用内的 JSON 导出功能备份待办。

## 使用

- 点击日期选择日程起点，双击日期直接新增。
- **快速添加**：标题里直接写「明天晚上8点 和导师开会」「周日下午3点半 提交论文」「九点半 晨会」「12月1日 生日提醒」，日期与时间会被自动识别并从标题中剔除；输入框下方会实时显示「✦ 已识别：……」。支持 今天/明天/后天/大后天/周X/下周X/X月X日，以及 凌晨/早上/上午/中午/下午/傍晚/晚上/深夜 + 数字（含中文数字与「点半」「9:30」写法）。
- 日历格子上的金色角标显示当天未完成待办的数量；悬停任意日期会弹出玻璃浮层，预览这一天的日程（已完成的显示划线）。
- **课程表**：点击月历上的「周课表」查看这一周的课程；月历用青色标记有课日期。今日概览会提示下一节课，课程与待办按时间合并显示，也能单独筛选。
- 点击「课表」导入教学系统导出的 `.xlsx`、`.xls`、CSV、TSV 或 ICS 文件。导入预览可调整表头行和字段列；每周排课按「第一教学周的周一」和学期周数换算成具体上课日期。若文件只标节次，可在课表设置里按每节填写实际时间，导入后用于提醒。课程支持手动新增、编辑、调课、取消单次课程和恢复导入内容。
- 课程默认提前 20 分钟提醒，可在编辑单次课程时更改为 5 分钟、10 分钟、30 分钟、1 小时或不提醒。提醒与待办共用托盘、系统通知和桌宠；同一场课程的提醒会持久去重。电脑恢复运行时，若课程仍未开始会补发提醒；课程开始超过 5 分钟后跳过。
- **主题外观**：标题栏调色板按钮可切换「潮汐 / 深海 / 暮樱 / 星芒」四款海色主题，选中色、按钮、进度环与极光氛围一起换色，偏好自动保存。
- 切换「当天」「近四天」「全部」查看不同范围；搜索匹配标题和备注，可配合「隐藏已完成」使用。筛选偏好自动保存。
- 点击圆圈完成事项（有音效与光晕），点击标题或时间编辑，悬停可删除；删除后 10 秒内可撤销。
- **拖拽改期**：把未完成的待办卡片直接拖到月历的某一天上，即可改期（修改后会重新计算提醒）。
- 完成今天最后一件待办时，おおくじら会庆祝：气泡上浮特效 + 音效 + 台词。
- 点击右上角「今日完成」打开**本周回顾**：最近 7 天的完成柱状图、本周总数与连续打卡天数，底部可**导出 / 导入 JSON 备份**（导入会整体替换当前待办，并做完整校验）。
- **首次启动**时おおくじら会用气泡教你三件事：快速添加、召唤桌宠；任意点击即可跳过。
- 左上区域会在问候语、下一件待办倒计时、连续完成天数、本周完成数之间轮播。

## おおくじら（桌宠级互动）

- **光标陪伴**：她会轻轻朝鼠标位置偏移；在旁边停留一会儿会主动凑近。桌宠动作主要通过全身姿势和重心变化呈现。
- **反应系统**：新增、完成、删除、置顶、提醒、深夜等场景都有对应台词与表情变化（自动表情模式下会短暂切换表情再还原）；长时间不操作她会轻声闲聊。
- **陪伴面板**：点击右下角头像展开。表情可选「随时间 / 微笑 / 害羞 / 小憩」，「随时间」在 23:00～次日 06:00 显示困倦表情。点击立绘或「全身」按钮查看全身立绘。
- **桌面桌宠**：点击标题栏的鲸鱼图标把她召唤到桌面——透明置顶小窗、全身待机和正侧向步态；横向移动时先转身进入侧面步行，停下再转回正面。首次出现会走近、停步、回身挥手。久坐时会伸展或坐下休息，完成待办时轻跳，夜间蜷坐入睡并缓慢呼吸；拖拽时身体、裙摆和鲸尾随重心变化，松手后落稳。她会隔着屏幕看你的光标，在旁边停留一会儿会主动**凑过来**看看你在干嘛；透明区域不挡鼠标，双击跳回日历，右键有菜单。位置、主题与开关状态都会记住，下次启动自动回来。她也会播报待办提醒，专注时安静下沉陪伴，并遵循系统的减少动态效果设置。
- **专注模式**：左下角「专注」按钮（或 Alt + F）打开番茄钟——25/45/15 分钟倒计时环，结束时音效、庆祝气泡与系统通知一起提醒你。
- **托盘常驻**：点关闭按钮不是退出，而是收进系统托盘继续提醒；托盘图标单击/双击打开日历，菜单可打开窗口、召唤桌宠或真正退出。
- **音效**：WebAudio 实时合成（无外部音频文件），完成/新增/删除/提醒/庆祝各有音色；标题栏喇叭图标可一键静音。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / Cmd + Alt + C | 全局呼出 / 收起主窗口（任何界面有效） |
| Ctrl / Cmd + N | 新增待办 |
| Ctrl / Cmd + K | 搜索日程 |
| Alt + T | 返回今天 |
| Alt + F | 专注模式 |
| 方向键 | 在已聚焦的月历中移动日期 |
| Enter / 空格 | 选择已聚焦日期、操作按钮 |
| Esc | 关闭编辑框；收起おおくじら；清空搜索 |

## 提醒与数据

**应用保持开启或最小化时才会提醒；关闭应用后停止提醒。** 系统通知仍受 Windows 通知设置和勿扰模式影响。

主进程每 15 秒检查一次，并在电脑恢复唤醒时检查。启动或唤醒后补发最近 24 小时内未提醒的到期事项；多个事项会合并为一条通知。已完成的事项不提醒，已提醒的时间会写入数据文件，重启后不会再次提醒同一时间。修改日期或时间后会重新计算提醒。

沿用原来的应用名和 `todos.json` 文件，兼容旧版待办（新增的 `completedAt` 字段用于打卡统计，旧数据没有该字段也能正常读取）。在 Windows 上，数据通常位于 `%APPDATA%\desktop-calendar-reminder\`：

- `todos.json`：当前待办，通过临时文件写入后再替换。
- `courses.json`：学期设置、导入的课程实例、单次调课和提醒记录，独立于待办备份保存。
- `todos.json.bak`：上一次成功保存前的有效数据。
- `todos.json.corrupt-时间戳`：读取异常并从备份恢复时保留的损坏原文件。
- `window-state.json`：窗口位置、尺寸和置顶状态。
- `pet-state.json`：桌宠开关与位置。

课程表的 Excel 文件在本机读取，不会上传。导入支持有表头的课程列表，也能识别星期一到星期日分列、课程内容写在对应格子里的周课表；星期格子可自动解析周次、节次和地点。图片或 PDF 排版仍需先转换成表格，其他特殊格式可通过样例继续适配。

如果当前数据和备份均无法读取，应用会显示错误并停止写入，保留原文件。

源文件和测试样例不包含真实用户的待办或课程数据。

## Ookujira 陪伴升级（2026-11-16）

角色名「おおくじら / Ookujira」，温柔慢热、爱抱枕、轻微嘴硬，日程提醒可靠。主界面和桌宠共用场景词库，近期台词避免重复；主动闲聊至少间隔15分钟，专注时保持安静。

桌宠右键可选择坐下、递抱枕睡觉、唤醒、摸头和恢复自动作息。坐姿持续一分钟，抱枕睡眠保持到唤醒；拿枕、下蹲、落座、睡眠和起身使用专门过渡帧。点击头部、尾部和连续点击有不同反馈，双击仍打开日历。

点击日期下方天气栏设置城市、搜索选择或关闭天气联动。默认武汉，Open-Meteo提供天气模型估计，无需密钥，每20分钟刷新；断网保留缓存并标记连接失败，超过90分钟停止天气动作。白天晴朗会晒太阳，下雨撑伞，炎热扇风，寒冷捧杯，下雪接雪花；专注与睡眠期间不启动天气动作。城市与缓存保存在原用户数据目录的 `weather-state.json`。

鲸鱼图标为项目原创SVG，另附PNG及16/32/48/64/128/256多尺寸ICO。`npm run build:icon`重新生成。原待办数据目录保持兼容。新增 `npm run test:companion`验证城市设置、坐卧、起身、撑伞和专注抑制；`npm test`包含天气缓存和过期判断测试。

### 拖拽与动作稳定性修复

拖拽使用Electron原生DIP屏幕坐标与固定按下锚点，每个渲染帧最多一个更新请求；窗口移动产生的局部鼠标事件不再参与位移计算。拖动中按实际位移方向切换动作：左右移动使用对应朝向的侧面步行，上移提起、下移放下；停住约180毫秒后停止迈步，横向松手后转回正面，竖向松手后落稳，并保存位置。方向判断累计至少3像素位移、反向至少6像素、切换间隔至少160毫秒，避免轻微抖动造成反复转向。拖动时暂停自动游走和额外身体摇晃。每个图集帧在原图上独立裁切，消除相邻尾巴残片。动作使用逐帧串行计时，普通动作每帧至少260毫秒，生活动作至少240毫秒，步行帧间隔140毫秒；程序短暂卡顿后仍逐帧停留，转身完成后才开始移动。

`npm run test:pet`新增固定锚点拖拽、光标静止抗抖、左右方向步行、上下提放、停步稳定、渲染阻塞后的帧停留以及彩色相邻帧泄漏的像素检查。
